# Mini-Compiler (Python)

## Features

- **Lexical Analysis:** Tokenizes source code into lexemes, categorizing them into keywords, operators, identifiers, etc.
- **Symbol Table:** Creates a symbol table for identifiers with their memory locations.
- **Error Checking:** Identifies common syntax errors like missing colons and mismatched parentheses.
- **AST Generation:** Converts Python code into an Abstract Syntax Tree (AST).
- **Parse Tree Generation:** Displays the parse tree in a dictionary format with identifiers and expressions extracted from the AST.
